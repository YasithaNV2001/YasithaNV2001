## 🚀 &nbsp;Featured Projects

### 1. Petition Moderation Assistant &nbsp;<sub>MSc capstone, 2026 · [`repo`](https://github.com/YasithaNV2001/Petition-Moderation-Assistant-CS5998-Capstone-Project)</sub>

An NLP assistant on **128k UK Parliament petitions** that predicts moderation outcomes and finds duplicate petitions, with a leakage-safe, time-split evaluation.

| Task (test set) | Baseline | Final |
|---|---|---|
| Predict the outcome (7 classes) | TF-IDF + linear SVM: macro-F1 0.415 | Fine-tuned DistilRoBERTa + similarity fusion: **macro-F1 0.583**, 76.0% accuracy |
| Find the duplicate petition | BM25: Recall@5 0.864 | Hybrid BM25 + MiniLM: **Recall@5 0.941** |

`Python` · `PyTorch` · `Hugging Face` · `scikit-learn` · `BM25` · `sentence embeddings`

### 2. ThumGEN: AI Thumbnail Generator &nbsp;<sub>[`live`](https://thum-gen-client.vercel.app) · [`repo`](https://github.com/YasithaNV2001/ThumGEN)</sub>

A full-stack MERN app that generates YouTube thumbnails with AI through a switchable provider (Google Gemini or Cloudflare Workers AI).
- Secure sessions, input validation (Zod), rate limits, and a credit system that refunds failed AI calls
- **21 automated tests** (Vitest, Supertest, in-memory MongoDB) run in GitHub Actions on every pull request

`React` · `TypeScript` · `Node.js` · `Express` · `MongoDB` · `Vercel`

### 3. ApparelFlow ERP &nbsp;<sub>[`live`](https://apparelflow-erp-six.vercel.app) · [`repo`](https://github.com/YasithaNV2001/apparelflow-erp)</sub>

`Next.js` · `TypeScript` · `PostgreSQL` · `Drizzle` · `Vitest`
